# PowerShell Script Quest

A 15-day series of 60 practical PowerShell exercises.  
Four challenges per day covering scripting, automation, system information, file handling, and common administrative tasks.

These exercises are written for intermediate practice. Solutions are provided so you can compare your approach after attempting each problem.

## How to use

1. Clone the repository.
2. Work through one day at a time.
3. Try the exercises yourself before reading the solutions.
4. Open a pull request if you want to suggest improvements. All PRs are reviewed before merging.

```powershell
git clone https://github.com/rscalderonb/powershell-script-quest-15-day-challenge.git
cd powershell-script-quest-15-day-challenge
```

## Structure

Exercises are organized under the `days/` folder. Each day file contains four problems with a short description, hints, and a sample solution.
